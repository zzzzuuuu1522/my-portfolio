# 邹雨婷的个人作品集

用于展示个人项目、技术文章与简历的静态求职作品集，目标方向为 Java 后端 / 全栈开发实习。

## 技术栈

- Astro
- Tailwind CSS
- DaisyUI
- Astro Content Collections

## 本地运行

```bash
pnpm install
pnpm run dev
```
